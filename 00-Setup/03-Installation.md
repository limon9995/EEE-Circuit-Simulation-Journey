# 🛠️ OrCAD X Installation

This guide documents the installation process for OrCAD X after obtaining
Cadence academic access.

---

## 📋 Prerequisites

Before starting the installation, make sure you have:

- A valid Cadence account
- Valid academic/student access
- OrCAD X installer
- Stable internet connection
- Sufficient storage space
- Windows PC compatible with the current OrCAD X release

---

# 1️⃣ Run the Installer

Locate the downloaded installer:

`OrCADXInstall.exe`

Double-click the installer to start the setup process.

Windows may ask for permission to run the installer.

Allow the installer to continue.

---

# 2️⃣ Accept the License / Terms

Read the displayed license agreement and terms.

If you agree with the terms, select the required agreement option and continue.

---

# 3️⃣ Choose Installation Location

The installer will ask where the required installation files should be stored.

You can use the default location or select another drive/location
if you have a specific reason to do so.

### 💡 Recommendation

For a normal student installation, the default location is usually sufficient.

Avoid changing the location unless you know why you need a different path.

---

# 4️⃣ Download Installation Files

After the initial setup, the installer may connect to Cadence servers
and download the required software packages.

This requires an active internet connection.

The download time depends on:

- Internet speed
- Cadence server availability
- Selected software components

### ⚠️ Do not interrupt the process

Avoid shutting down the computer or closing the installer while
the required files are being downloaded.

---

# 5️⃣ Complete the Installation

After the required files have been downloaded, the installer continues
with the software installation.

Wait until the installation process is completed successfully.

---

# 6️⃣ Launch OrCAD X

After installation, open OrCAD X from the Windows Start Menu or
the shortcut created during installation.

The exact interface may vary depending on the software version.

---

# 7️⃣ Verify the Installation

A successful installation should allow you to launch the OrCAD X environment.

The next goal is to verify that the required PSpice functionality
is available.

---

# 🔐 Important

Do not upload the following to GitHub:

- License files
- License keys
- Support IDs
